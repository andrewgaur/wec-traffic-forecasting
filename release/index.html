How the replay works +

A crossing is the cutoff

The selected car's completed lap sets the forecast time. A car enters the known field only after it has crossed the finish line. The table always uses its latest crossing at or before that cutoff.

Start with recent pace

The baseline takes the median of up to three clean completed laps. Scripted delay laps are excluded. Reveal the next synthetic lap to compare it with the estimate. Changing the car or lap hides the outcome again.

Development status

This standalone demo uses invented timing data. The Python project is building race replay and event filtering using official files locally. A trained traffic model and evaluation on held-out races remain future work.
