# WEC Traffic Forecasting demo

Open `index.html` in a browser. It needs no build step or dependencies.

The demo replays invented lap records. Pick a Hypercar and completed lap to see the latest records available at that instant, a median recent pace baseline, and the next synthetic lap as a reference outcome. It demonstrates the current project's time ordering and forecast origin concept. It does not claim a trained traffic model or real race performance.

To publish this folder with GitHub Pages, put its contents at the root of a `gh-pages` branch and set the Pages source to that branch's root. The public URL will be `https://andrewgaur.github.io/wec-traffic-forecasting/` once GitHub reports deployment complete.
