# Source Data folder

On my local machine, I store the official race data csvs here. The data is grouped by race and year, and each contains the race-specific, hourly data that the program actually analyzes. While I won't (and probably can't) include the actual csv files in the repo, they can be found at `https://fiawec.alkamelsystems.com/`

In my directory, I keep the final analysis file, which can be found in the final hour folder on the WEC website, as well as hourly data in case I need it in the future.

To obtain and use the data yourself, you can download the official session timing data from the official WEC website, and place the appropriate race files into it's corresponding folder. All hourly data is placed into the race folder; you don't have to separate the hourly data files into their own individual folder.
