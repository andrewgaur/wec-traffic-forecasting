What could a car know right now?

Step through finish line crossings. Pick a Hypercar and a completed lap to see the information available when forecasting its next lap. Compare a simple recent pace baseline with the simulated next lap.

This public demo uses invented lap data. The pace baseline is an illustrative calculation, not a trained traffic forecasting model. The project is still building race replay and event filtering.

What this demonstrates

Replay first, then model

For a real forecast, the car's next lap time stays hidden until after the forecast point. Here you can reveal it for inspection. The same replay rule will prevent later laps from entering traffic features. Pit and flag laps need explicit filtering before fitting a pace model.

Current development uses official race timing files locally. Those files are not bundled here. This toy race shows the interface and timing logic without redistributing source data or presenting a model result the project has not earned.
